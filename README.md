# Segaloka

Segaloka is a modular travel ecosystem platform.

Local project path:

D:\Segaloka

## Development Principles

- Domain-oriented modular architecture
- Contract-first development
- Vertical slice implementation
- PostgreSQL as transactional source of truth
- Realtime or near-realtime production freshness
- Automatic cache invalidation/revalidation
- No manual cache clearing as a normal workflow
- Low-blast-radius changes
- Strict tenant isolation and authorization
- ID, EN, and AR localization with RTL support
- Light, Dark, and System appearance support
- PowerShell-first local development workflow
